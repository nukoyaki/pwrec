# pwrec

a quickly thrown together pipewire video recorder,</br>
this was made mostly for personal use so don't expect support,</br>
its made specifically for my use case and may not work for yours</br>

to use it just
```bash
make -j $(nproc) install
```
and run the pwrec command, it prints out the instructions and what can be passed for you if you feed it zero arguments
